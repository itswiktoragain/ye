# Wallfall 2.0 - Fabric 1.21.4
Walk forward into a solid wall to attach. Directional gravity physically accelerates
you toward the surface; W/S climb/descend its local plane; A/D traverse it.
Use SPACE to leap away **without switching gravity**; you fall back toward the
same surface. Leave a ledge and normal gravity resumes.
Climb to a solid overhead ceiling to flip gravity up and walk upside-down.
A slab block placed in sideways or upward gravity becomes a rotated slab
with real rotated geometry, stored original slab material, render and collision.
Other blocks continue to place normally (full arbitrary block rotation still
not implemented).
Install Minecraft 1.21.4, Fabric Loader, Fabric API and Java 21.
