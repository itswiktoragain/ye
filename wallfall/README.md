# Wallfall - Fabric 1.21.4

Walk forward into a solid wall to attach; W/S to move up/down the wall, A/D to strafe.
Run beyond the wall and gravity returns to normal. Jump detaches.
Minecraft 1.21.4 + Fabric Loader + Fabric API, Java 21.
Build with Gradle 8.12: `gradle build`, then install `build/libs/wallfall-fabric-1.21.4-1.0.0.jar`.
This is simulated wall gravity with the player's standard upright hitbox, not complete rotated collision physics.
